# Instrucciones del repositorio

- Todo commit nuevo y título de PR debe cumplir Conventional Commits según CONTRIBUTING.md.
- Trabajar en develop o en una rama de funcionalidad; integrar main mediante PR.
- Antes de publicar, ejecutar las pruebas del validador y revisar git diff --check.
- No versionar metadatos, señales, datos de pacientes, resultados derivados ni credenciales.
- Mantener los comandos de acceso a AWS y descarga en scripts/heedb.py.
